# SpaceDrum downloads

Official downloads for SpaceDrum owners. Everything here is signed by SpaceDrum.

## COMMAND app

The COMMAND app is the companion app for your SpaceDrum.

| Computer | File |
|---|---|
| Mac (Apple Silicon and Intel) | the `.dmg` on the latest release |
| Linux (Raspberry Pi and other Debian computers) | the `.deb` or `.tar.gz` on the latest release |

Open the [latest release](../../releases/latest) and download the file for your computer.

## SpaceDrum software updates

Software updates for the instrument are `.spd` files. They are encrypted and signed: only a SpaceDrum can open one, and a changed file is refused.

1. Download the `.spd` file from the latest release marked **Instrument update**.
2. Copy that one file onto a USB drive.
3. Plug the drive into your SpaceDrum and switch it off and on again.
4. The update installs while the instrument starts. Remove the drive when it finishes.

Install one update at a time, and keep the previous version's file in case you want to go back.

## Check your download

Each release lists a checksum for every file. On a Mac or Linux computer run `shasum -a 256 <file>` and compare the result with the release notes.
